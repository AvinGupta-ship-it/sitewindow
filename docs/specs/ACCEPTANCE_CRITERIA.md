# Acceptance Criteria

Each criterion is measurable and is checked either by an automated test (`tests/`), by a validation runner (`sitewindow validate`), by the release script (`scripts/make_release.py`), or by a documented manual audit recorded in `AUDIT.md` at release. A component is complete only when every applicable criterion is satisfied and the evidence is recorded.
